# Quiz brise-glace UX v2 — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** timer par question et chrono global, téléphone joueur au style « Plateau TV » avec flash de résultat synchronisé, écran animateur « Régie » fluide (clavier, optimiste, colonne joueurs avec avatars), consignes explicites, médias par URL.

**Architecture :** trois nouveaux modules purs partagés front/serveur (`quiz/lib/avatars.js`, `quiz/lib/timing.js`, `quiz/lib/media-url.js`) portent les règles testables ; le serveur ne change que pour l'avatar, `openedAt`/`durationSec` et l'action `extend` ; le validateur et la liste blanche de contenu acceptent `timeLimit`, `question` et `media.url` ; l'app joueur et l'écran animateur sont réécrits sur les mêmes briques (`dom.js`, `api.js`, modules de jeux).

**Tech Stack :** Node 22, `node:test`, Netlify Functions + Blobs (inchangés), vanilla JS sans build, Playwright/Chromium headless hors repo pour la vérification (déjà installé sous `/tmp/claude-1000/pw/`, sinon `npm i playwright` dans un dossier temporaire).

**Spec :** `docs/superpowers/specs/2026-10-14-quiz-ux-v2-design.md`

## Global Constraints

- Durées par défaut : `human_or_ai` 15 s · `bet_machine` 20 s · `investigation` 30 s · `prompt_duel` 30 s ; `timeLimit` entier 5–120.
- Chrono global : `durationSec` = somme des durées effectives + 60 s, arrondie à la minute supérieure ; `extend` ±60 s, minimum 60 s ; pas de révélation automatique.
- Timer = choix + confiance ; à 0 sans choix → non répondu (rien n'est envoyé) ; à 0 après le choix → envoi avec confiance `1`. **Aucun effet sur le score.**
- Pendant le jeu : flash neutre « Réponse enregistrée » (pas de vrai/faux, pas de points de rapidité). Vrai/faux seulement à la révélation, flash BRAVO / RATÉ / PAS RÉPONDU / TROP TARD.
- Polling joueur 1,5 s en `reveal`/`done`, 3 s sinon ; polling animateur 1 s.
- Thème « Plateau TV » **uniquement** sur le téléphone joueur (`quiz/game.css`, variables `--game-*`) ; écran animateur et site dans la charte ; jamais de redéclaration des tokens de `design/tokens.css`.
- Résultat jamais porté par la seule couleur ; animations coupées sous `prefers-reduced-motion` ; boutons joueur ≥ 56 px.
- Médias par URL : `https` uniquement ; YouTube (`watch?v=`, `youtu.be/`, `shorts/`, `t=`/`start=`), Vimeo, images `.jpg .jpeg .png .webp .gif .avif` (`alt` requis), vidéos `.mp4 .webm .mov` ; TikTok/Instagram/X/Facebook refusés ; ancienne forme toujours valide.
- Consignes (texte exact) : « Ce contenu a-t-il été créé par un humain ou par une IA ? » · « On a posé cette question à une IA. Que va-t-elle répondre ? » · « Quelle réponse de l'IA pose problème ? » · « Lequel de ces prompts donnera le meilleur résultat ? » ; `question` optionnelle ≤ 300 caractères.
- Avatars : liste fermée `AVATARS`, validée par le serveur.
- Aucune réponse envoyée aux joueurs avant la révélation (liste blanche maintenue).

### Écart assumé par rapport à la spec

La partie `demo` reçoit un `timeLimit` d'exemple mais **pas** de média par URL : aucune URL publique à la fois vérifiée et neutre (qui ne trahit pas la réponse) n'est disponible ; `media.url` est couvert par les tests unitaires et documenté dans `docs/quiz.md`.

```js
// Question timers and the host's countdown. The timer never changes the score.
export const DEFAULT_TIME_LIMITS = { human_or_ai: 15, bet_machine: 20, investigation: 30, prompt_duel: 30 };
export const MIN_TIME_LIMIT = 5;
export const MAX_TIME_LIMIT = 120;

export const timeLimitFor = (q) => (Number.isInteger(q.timeLimit) ? q.timeLimit : (DEFAULT_TIME_LIMITS[q.game] ?? 20));

// Every question's timer plus a 60 s margin, rounded up to the minute.
export function gameDurationSec(questions) {
  const total = questions.reduce((sum, q) => sum + timeLimitFor(q), 0) + 60;
  return Math.ceil(total / 60) * 60;
}

export function remainingSec(state, nowMs = Date.now()) {
  if (!state?.openedAt || !state?.durationSec) return null;
  const elapsed = (nowMs - Date.parse(state.openedAt)) / 1000;
  return Math.max(0, Math.round(state.durationSec - elapsed));
}

export const formatClock = (sec) => `${String(Math.floor(sec / 60)).padStart(2, "0")}:${String(sec % 60).padStart(2, "0")}`;
```

```js
// Turns `media.url` into a playable media description. Shared by the validator
// (organisers get a clear error) and the front (rendering). The legacy explicit
// form ({kind, provider, id, src}) is returned unchanged.
const IMAGE_EXT = ["jpg", "jpeg", "png", "webp", "gif", "avif"];
const VIDEO_EXT = ["mp4", "webm", "mov"];
const SOCIAL = ["tiktok.com", "instagram.com", "x.com", "twitter.com", "facebook.com", "fb.watch"];

const hostIs = (host, domain) => host === domain || host.endsWith(`.${domain}`);

export function parseTime(value) {
  if (value === null || value === undefined || value === "") return undefined;
  if (/^\d+$/.test(value)) return Number(value);
  const m = /^(?:(\d+)h)?(?:(\d+)m)?(?:(\d+)s)?$/.exec(value);
  if (!m || !(m[1] || m[2] || m[3])) return undefined;
  return Number(m[1] ?? 0) * 3600 + Number(m[2] ?? 0) * 60 + Number(m[3] ?? 0);
}

export function resolveMedia(media) {
  if (!media || typeof media !== "object") return { error: "media manquant" };
  if (media.url === undefined) return media;
  let u;
  try {
    u = new URL(media.url);
  } catch {
    return { error: "media.url invalide" };
  }
  if (u.protocol !== "https:") return { error: "media.url doit être en https" };
  const host = u.hostname.toLowerCase().replace(/^(www|m)\./, "");
  if (SOCIAL.some((d) => hostIs(host, d))) {
    return { error: "réseaux sociaux non pris en charge (TikTok, Instagram, X, Facebook) : utilisez YouTube, Vimeo ou un fichier vidéo" };
  }
  const extra = {};
  if (media.alt !== undefined) extra.alt = media.alt;
  if (media.fallback !== undefined) extra.fallback = media.fallback;
  const times = (fromUrl) => {
    const out = {};
    const start = media.start ?? fromUrl;
    if (start !== undefined) out.start = start;
    if (media.end !== undefined) out.end = media.end;
    return out;
  };

  if (hostIs(host, "youtube.com") || host === "youtu.be") {
    let id;
    if (host === "youtu.be") id = u.pathname.slice(1).split("/")[0];
    else if (u.pathname === "/watch") id = u.searchParams.get("v");
    else id = /^\/(?:shorts|embed|live)\/([^/]+)/.exec(u.pathname)?.[1];
    if (!id || !/^[A-Za-z0-9_-]{6,20}$/.test(id)) return { error: "identifiant YouTube introuvable dans l'URL" };
    return { kind: "video", provider: "youtube", id, ...times(parseTime(u.searchParams.get("t") ?? u.searchParams.get("start"))), ...extra };
  }
  if (hostIs(host, "vimeo.com")) {
    const id = /\/(\d+)(?:\/|$)/.exec(u.pathname)?.[1];
    if (!id) return { error: "identifiant Vimeo introuvable dans l'URL" };
    return { kind: "video", provider: "vimeo", id, ...times(parseTime(/t=([0-9hms]+)/.exec(u.hash)?.[1])), ...extra };
  }
  const ext = /\.([a-z0-9]+)$/i.exec(u.pathname)?.[1]?.toLowerCase();
  if (IMAGE_EXT.includes(ext)) return { kind: "image", src: u.href, ...extra };
  if (VIDEO_EXT.includes(ext)) return { kind: "video", src: u.href, ...times(undefined), ...extra };
  return { error: "type de média non reconnu : YouTube, Vimeo, image (.jpg, .png, .webp, .gif, .avif) ou vidéo (.mp4, .webm, .mov)" };
}
```

```js
// Small animation helpers shared by the player app and the host screen.
export const reducedMotion = () => typeof matchMedia === "function" && matchMedia("(prefers-reduced-motion: reduce)").matches;

// Animates a number from 0 to `target` in `el` (instant when motion is reduced).
export function countUp(el, target, ms = 1200) {
  if (reducedMotion()) {
    el.textContent = String(target);
    return;
  }
  const t0 = performance.now();
  const step = (t) => {
    const k = Math.min(1, (t - t0) / ms);
    el.textContent = String(Math.round(target * k));
    if (k < 1) requestAnimationFrame(step);
  };
  requestAnimationFrame(step);
}
```

```js
import { h } from "./dom.js";
import { resolveMedia } from "./media-url.js";

export function renderMedia(media) {
  if (!media) return null;
  const m = resolveMedia(media);
  if (m.error) return h("p", { class: "error" }, `Média indisponible : ${m.error}`);
  switch (m.kind) {
    case "text":
      return h("blockquote", { class: "media media-text" }, m.text);
    case "code":
      return h("pre", { class: "media media-code" }, h("code", {}, m.text));
    case "image":
      return h("img", { class: "media media-image", src: m.src, alt: m.alt ?? "" });
    case "video":
      return renderVideo(m);
    default:
      return h("p", { class: "error" }, "Média non pris en charge.");
  }
}

function renderVideo(m) {
  if (m.src) {
    return h("video", { class: "media media-video", src: m.src, controls: true, playsinline: true, preload: "metadata" });
  }
  const start = m.start ?? 0;
  const src =
    m.provider === "youtube"
      ? `https://www.youtube-nocookie.com/embed/${encodeURIComponent(m.id)}?start=${start}${m.end ? `&end=${m.end}` : ""}&rel=0&playsinline=1`
      : `https://player.vimeo.com/video/${encodeURIComponent(m.id)}#t=${start}s`;
  return h(
    "div",
    { class: "media-video-wrap" },
    h("iframe", { class: "media media-video", src, title: "Vidéo", loading: "lazy", allow: "autoplay; encrypted-media; picture-in-picture", allowfullscreen: true }),
    m.fallback ? h("a", { class: "media-fallback", href: m.fallback, target: "_blank", rel: "noopener" }, "La vidéo ne se charge pas ? Voir l'image") : null,
  );
}

// Resolves when a question's timer may start: once a video extract has had time to play.
// Embeds: wait (end − start) seconds when known. Video files: wait for « ended », capped by
// the file's duration; if its metadata never arrives within 3 s, don't hold the timer.
export function waitForMedia(media, container) {
  const m = media ? resolveMedia(media) : null;
  if (!m || m.error || m.kind !== "video") return Promise.resolve();
  if (m.provider) {
    const sec = m.end !== undefined ? m.end - (m.start ?? 0) : 0;
    return new Promise((resolve) => setTimeout(resolve, Math.min(Math.max(sec, 0), 120) * 1000));
  }
  const video = container.querySelector("video");
  if (!video) return Promise.resolve();
  return new Promise((resolve) => {
    let done = false;
    const finish = () => {
      if (!done) {
        done = true;
        resolve();
      }
    };
    video.addEventListener("ended", finish, { once: true });
    const capByDuration = () => setTimeout(finish, Math.min(video.duration || 0, 120) * 1000 + 500);
    if (video.readyState >= 1) capByDuration();
    else video.addEventListener("loadedmetadata", capByDuration, { once: true });
    setTimeout(() => {
      if (video.readyState < 1) finish();
    }, 3000);
  });
}
```

```js
const UID_KEY = "aic-quiz-uid";

// localStorage can throw (private mode, blocked storage): the game must still work.
function read(key, fallback) {
  try {
    const raw = localStorage.getItem(key);
    return raw ? JSON.parse(raw) : fallback;
  } catch {
    return fallback;
  }
}
function write(key, value) {
  try {
    localStorage.setItem(key, JSON.stringify(value));
  } catch {
    /* state stays in memory for this tab */
  }
}
// crypto.randomUUID is only available in secure contexts (not plain http on a LAN IP).
function uuid() {
  if (typeof crypto.randomUUID === "function") return crypto.randomUUID();
  const b = crypto.getRandomValues(new Uint8Array(16));
  b[6] = (b[6] & 0x0f) | 0x40;
  b[8] = (b[8] & 0x3f) | 0x80;
  const x = [...b].map((n) => n.toString(16).padStart(2, "0")).join("");
  return `${x.slice(0, 8)}-${x.slice(8, 12)}-${x.slice(12, 16)}-${x.slice(16, 20)}-${x.slice(20)}`;
}
function uid() {
  let id = read(UID_KEY, null);
  if (!id) {
    id = uuid();
    write(UID_KEY, id);
  }
  return id;
}

const blank = () => ({ pid: null, pseudo: null, avatar: null, answers: {} });
const stored = read(STORE_KEY, null);
let me = stored && typeof stored === "object" && stored.answers && typeof stored.answers === "object" ? stored : blank();

// qids queued or being sent, so a poll never sends the same answer twice.
let sendQueue = Promise.resolve();
const inFlight = new Set();
let unsentNote = null; // the « non envoyée » line of the current question screen
const unsentCount = () => Object.entries(me.answers).filter(([qid, a]) => !a.sent && !a.late && !inFlight.has(qid)).length;

// ---------- question timer ----------
let timer = null;
function stopTimer() {
  if (timer) clearInterval(timer);
  timer = null;
}
function startTimer(q, timerEl, fill, secs, onExpire) {
  stopTimer();
  const total = timeLimitFor(q) * 1000;
  const deadline = Date.now() + total;
  const tick = () => {
    const left = Math.max(0, deadline - Date.now());
    fill.style.width = `${(left / total) * 100}%`;
    secs.textContent = String(Math.ceil(left / 1000));
    timerEl.classList.toggle("is-low", left <= 5000);
    if (left === 0) {
      stopTimer();
      onExpire();
    }
  };
  timer = setInterval(tick, 200);
  tick();
}

async function main() {
  if (!session) return message("Lien incomplet", "Scanne le QR code affiché par l'animateur.");
  try {
    game = await api.game(session);
  } catch (err) {
    return message(err.status === 404 ? "Partie introuvable" : "Connexion impossible", "Vérifie le lien puis recharge la page.");
  }
  state = game.state;
  if (state.status === "closed" && Object.keys(me.answers).length) {
    me = blank(); // answers only exist after an open game: the host reset while we were away
    save();
  }
  if (!me.pid && !REVEALED.has(state.status)) renderJoin();
  else render();
  setTimeout(loop, 3000);
}

// Faster polling during the reveal so phones follow the shared screen.
async function loop() {
  try {
    await refresh();
  } catch (err) {
    console.warn("[quiz] poll", err);
  }
  setTimeout(loop, REVEALED.has(state?.status) ? 1500 : 3000);
}

let flashedIndex = null; // the revealed question whose BRAVO/RATÉ flash already played

async function refresh() {
  const next = await api.state(session);
  const previous = state;
  const statusChanged = next.status !== previous.status;
  if (statusChanged) {
    game = await api.game(session); // answers and stats arrive with the reveal
    results = null;
    if (!REVEALED.has(next.status)) flashedIndex = null;
    if (next.status === "closed") {
      me = blank(); // the host reset the game
      save();
    }
  }
  state = next;
  // While open, unsent answers are retried; once revealed, one last try gets
  // the 409 « not_open » that marks them as too late.
  if (state.status !== "closed") flushUnsent();
  if (!statusChanged && next.revealIndex === previous.revealIndex) return;
  if (!me.pid && !REVEALED.has(state.status)) {
    // back from a reveal, or the host reset the game: show the join screen again;
    // otherwise keep it as is (and what the player is typing)
    if (REVEALED.has(previous.status) || next.status === "closed") renderJoin();
    return;
  }
  render();
}

function render() {
  if (state.status === "closed") return message("La partie va commencer…", `Tu joues en tant que ${me.pseudo}. Garde cette page ouverte.`);
  if (state.status === "open") return renderPlay();
  return renderReveal();
}

// Participation streak: consecutive answered questions (a skipped one resets it).
function streakLabel() {
  let n = 0;
  for (const q of game.questions) {
    const a = me.answers[q.id];
    if (!a) break;
    n = a.skipped ? 0 : n + 1;
  }
  return n >= 2 ? `🔥 ${n}` : "";
}

function renderPlay() {
  stopTimer();
  const q = game.questions.find((x) => !me.answers[x.id]);
  if (!q) return renderWaiting();
  const index = game.questions.indexOf(q);
  let picked = null; // the choice made, waiting for its confidence
  const fill = h("span", { class: "timer-fill" });
  const secs = h("span", { class: "timer-secs" }, String(timeLimitFor(q)));
  const timerEl = h("div", { class: "timer is-waiting", role: "timer", "aria-label": "Temps restant" }, h("span", { class: "timer-track" }, fill), secs);
  const stage = h("div", { class: "stage" });
  const question = GAMES[q.game].renderQuestion(q, (choice) => {
    picked = { choice };
    mount(
      stage,
      h(
        "div",
        { class: "confidence" },
        h("p", { class: "consigne" }, "Tu es sûr de toi ?"),
        h("div", { class: "choices" }, CONFIDENCE.map((c) => h("button", { class: "choice", type: "button", onclick: () => record(q.id, choice, c.value) }, c.label))),
        h(
          "button",
          {
            class: "link",
            type: "button",
            onclick: () => {
              picked = null;
              mount(stage, question);
            },
          },
          "↩ Changer de réponse",
        ),
      ),
    );
  });
  stage.append(question);
  unsentNote = h("p", { class: "unsent" }, unsentLabel(unsentCount()));
  mount(
    root,
    h(
      "section",
      { class: "screen play" },
      h("div", { class: "hud" }, h("span", {}, `${index + 1}/${game.questions.length}`), timerEl, h("span", {}, streakLabel())),
      unsentNote,
      stage,
    ),
  );
  waitForMedia(q.media, stage).then(() => {
    if (!stage.isConnected || me.answers[q.id]) return; // moved on meanwhile
    timerEl.classList.remove("is-waiting");
    startTimer(q, timerEl, fill, secs, () => (picked ? record(q.id, picked.choice, 1) : skip(q.id)));
  });
}

function record(qid, choice, confidence) {
  stopTimer();
  me.answers[qid] = { choice, confidence, sent: false };
  save();
  send(qid); // queued first, so the next screen does not flag it as unsent
  flashThen("saved", render);
}

// Timer ran out without a choice: nothing is sent, the question counts as unanswered.
function skip(qid) {
  me.answers[qid] = { skipped: true, sent: true };
  save();
  flashThen("timeout", render);
}

function send(qid) {
  if (inFlight.has(qid)) return;
  inFlight.add(qid);
  sendQueue = sendQueue
    .then(async () => {
      try {
        await deliver(qid);
      } finally {
        inFlight.delete(qid); // even on a throw, so the next poll retries it
      }
      showUnsent();
    })
    // a rejected chain would skip every later send: log and keep the queue alive
    .catch((err) => console.warn("[quiz] file d'envoi", err));
}

async function deliver(qid) {
  const pid = me.pid;
  const answer = me.answers[qid];
  if (!pid || !answer || answer.sent || answer.late) return; // reset meanwhile, or nothing left to send
  try {
    await api.answer(session, pid, qid, answer.choice, answer.confidence);
    answer.sent = true;
    save();
  } catch (err) {
    if (err.code === "unknown_player") {
      if (me.pid !== pid) return; // an earlier send already showed the join screen
      me = blank(); // game was reset while we were away
      save();
      return renderJoin();
    }
    if (err.code === "not_open") {
      answer.late = true; // the reveal has started: never resent
      save();
      if (REVEALED.has(state.status)) render();
      return;
    }
    console.warn("[quiz] réponse non envoyée, nouvel essai au prochain cycle", err);
  }
}

// Refreshes the « non envoyée » indicator without redrawing the question being answered.
function showUnsent() {
  if (unsentNote?.isConnected) unsentNote.textContent = unsentLabel(unsentCount());
}

function flushUnsent() {
  for (const [qid, answer] of Object.entries(me.answers)) if (!answer.sent && !answer.late) send(qid);
}

function renderWaiting() {
  stopTimer();
  const answered = game.questions.filter((q) => me.answers[q.id] && !me.answers[q.id].skipped).length;
  const unsent = unsentCount();
  mount(
    root,
    h(
      "section",
      { class: "screen center" },
      h("p", { class: "avatar-big" }, me.avatar ?? "☕"),
      h("h1", {}, "C'est dans la boîte !"),
      h("p", { class: "lead" }, `${answered}/${game.questions.length} répondues · en attente de la révélation…`),
      unsent ? h("p", { class: "error" }, `${unsent} réponse(s) pas encore envoyée(s), nouvel essai automatique.`) : null,
    ),
  );
}

async function loadResults() {
  if (!me.pid) return null;
  if (results === UNAVAILABLE) return null;
  if (!results) {
    try {
      results = await api.me(session, me.pid);
    } catch (err) {
      if (err.code === "unknown_player") {
        me = blank(); // game was reset while we were away: carry on as a spectator
        save();
        results = UNAVAILABLE;
        return null;
      }
      console.warn("[quiz] résultats indisponibles", err);
    }
  }
  return results;
}

function outcome(q, r) {
  if (me.answers[q.id]?.late) return "late";
  const mine = r?.answers?.[q.id];
  if (!mine) return "none";
  return mine.choice === q.answer ? "win" : "lose";
}

async function renderReveal() {
  stopTimer();
  const r = await loadResults();
  if (!REVEALED.has(state.status)) return; // a reset/reopen happened meanwhile
  const i = state.revealIndex;
  if (i >= game.questions.length) return renderProfile(r);
  const q = game.questions[i];
  const card = () =>
    mount(
      root,
      h(
        "section",
        { class: "screen reveal" },
        h("p", { class: "kicker" }, `Révélation · ${i + 1} / ${game.questions.length}`),
        GAMES[q.game].renderReveal(q, game.stats?.[q.id], r?.answers?.[q.id]),
        lateNote(me.answers[q.id]?.late),
      ),
    );
  if (!me.pid || flashedIndex === i) return card();
  flashedIndex = i;
  flashThen(outcome(q, r), () => {
    if (REVEALED.has(state.status) && state.revealIndex === i) card();
  });
}

  mount(
    root,
    h(
      "section",
      { class: "screen center" },
      h("p", { class: "avatar-big" }, r.avatar ?? me.avatar ?? p.emoji),
      h("p", { class: "kicker" }, r.pseudo),
```

```js
function readHostKey() {
  const match = location.hash.match(/(?:^#|&)key=([^&]+)/);
  if (match) {
    let key = match[1];
    try {
      key = decodeURIComponent(key);
    } catch {
      /* keep the raw value */
    }
    try {
      localStorage.setItem(KEY_STORAGE, key);
    } catch {
      /* not remembered: the fragment must be passed again next time */
    }
    history.replaceState(null, "", location.pathname + location.search);
    return key;
```
