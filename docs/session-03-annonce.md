## LinkedIn (version longue)

☕ **AI Coffee #03 — Sous le capot**
Ce soir, 21h00. En ligne. 12 places.

Tout le monde utilise des agents IA. Presque personne n'a vu ce qui part vraiment vers le modèle.

Au programme, trois présentations :

**1. Un agent IA de zéro** — récap de la série d'articles qui construit un agent en Python pur, sans LangGraph ni CrewAI. 13 étapes, un mécanisme à la fois : la boucle (qui existe avant le LLM), l'appel sans état, les tool calls, le JSON cassé, la compaction de contexte, les sous-agents. L'objectif n'est pas de faire un framework de plus, c'est de savoir quoi déboguer quand ça casse.

**2. Le prompt one-shot : 7 questions avant de lancer** — un bon résultat du premier coup n'est pas de la chance. C'est sept minutes de dialogue avec l'IA avant l'exécution. On les pose en direct, puis on lance une génération complète en un seul essai dans Claude Code.

**3. Du ticket au code livré automatiquement** — par Jean-Noé Kollo.

Pas de slides théoriques, pas de POC jetable. On ouvre le capot, on montre le code, on répond aux questions.
